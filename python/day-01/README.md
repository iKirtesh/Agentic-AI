# Day 1 — Python Fundamentals

**Theme:** Python setup, syntax, variables, data types, operators, strings, and input/output  
**Suggested time:** 4 hours  
**Project:** AI Task Assistant CLI

## Learning objectives

By the end of Day 1, you should be able to:

- Run a Python script from a terminal.
- Explain Python indentation and basic syntax.
- Create variables and identify common built-in data types.
- Use arithmetic, comparison, and logical operators.
- Convert strings to numeric values.
- Manipulate strings and use f-strings.
- Read input and display formatted output.

## Study schedule

| Time | Activity |
|---|---|
| 45 min | Install/check Python, run scripts, learn syntax and indentation |
| 45 min | Variables, naming, and data types |
| 45 min | Operators and type conversion |
| 45 min | Strings, input, output, and f-strings |
| 45 min | Build and run the mini-project |
| 15 min | Quiz, revision, and notes |

## Run the examples

From the repository root:

```bash
python python/day-01/code/hello.py
python python/day-01/code/task_assistant.py
python python/day-01/code/exercises.py
```

The task assistant requests interactive input. Try valid inputs first, then try invalid numeric values and note the error. Handling invalid input is a follow-up improvement.
