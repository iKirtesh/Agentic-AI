# Agentic AI — Structured Learning Repository

A hands-on, day-by-day learning path from Python fundamentals to production-minded agentic AI systems.

## Learning plan

- **Duration:** 3 months
- **Month 1:** Python, LLM fundamentals, tool calling, and a first full-stack AI assistant
- **Month 2:** RAG, stateful workflows, LangGraph, MCP, agent security, and evaluation
- **Month 3:** Production architecture, deployment, observability, and a portfolio-grade project
- **Daily practice:** Learn concepts, write code, complete exercises, test, and document lessons.

## Repository structure

```text
python/
├── README.md
└── day-01/
    ├── README.md
    ├── notes.md
    ├── assignments.md
    ├── requirements.txt
    ├── code/
    │   ├── hello.py
    │   ├── task_assistant.py
    │   └── exercises.py
    └── tests/
        └── test_task_assistant.py
```

Each learning day should contain readable notes, runnable code, exercises or assignments, and tests where appropriate.

## Start here

1. Open [Python learning path](python/README.md).
2. Follow [Day 1](python/day-01/README.md).
3. Read the [Day 1 notes](python/day-01/notes.md).
4. Complete [Day 1 assignments](python/day-01/assignments.md).
5. Run the code and tests using the instructions in the day folder.

## Principles

- Prefer understanding and small working implementations over copying tutorials.
- Keep examples beginner-friendly, then improve them with validation and tests.
- Never commit API keys, passwords, or local `.env` files.
- Build one coherent project progressively rather than starting over each week.
